# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a suspected security vulnerability. Use GitHub's **Report a vulnerability** option under this repository's Security tab to send a private report. If that option is unavailable, contact the maintainers privately through their GitHub profiles.

Include a description, affected versions or commit, reproduction steps, and the potential impact. Please give maintainers time to investigate before public disclosure.

## Supported versions

HackTrack is currently pre-1.0. Security fixes are applied to the latest `main` branch; older commits are not maintained separately.
